# Diagnóstico 360° — Conecta Cred

Landing page de venda do Diagnóstico 360°. É um único arquivo (`index.html`), sem dependências nem build.

## Ver localmente

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Suba o `index.html` na raiz do repositório.
2. No GitHub, vá em **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em alguns minutos a página fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Personalizar

- **Cores:** variáveis no início do `<style>` (`--primary` para os botões, `--gold` para títulos e detalhes, `--bg` para o fundo).
- **Pendências:** tudo que está entre `[colchetes]` ainda precisa ser preenchido (link do checkout, parcelas, vídeo, foto, rodapé).
